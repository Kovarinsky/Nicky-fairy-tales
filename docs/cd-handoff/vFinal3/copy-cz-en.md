# CZ/EN copy sheet

Czech (CZ) is the shipping language for all 21 screens. English (EN) is provided for future localization scaffolding only — no screen ships in English yet. Where a Czech string uses informal "vy/vaše" (formal-plural "you") — keep this register consistently; do not mix with informal "ty" anywhere.
